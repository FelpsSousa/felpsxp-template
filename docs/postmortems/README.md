# Postmortems

What went wrong in this project, why, and what changed because of it. They are blameless: the
subject is the system and the process that allowed the failure, not the person who was at the
keyboard.

Write one for any incident that reached users, lost data, or took more than an hour to understand.
Copy [`template.md`](template.md) to `YYYY-MM-DD-short-title.md`. Add it to the list below in the
same pull request as the fix, or right after it.
